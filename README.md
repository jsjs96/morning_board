# 우리 반 아침 게시판

교실 TV나 전자칠판에 띄워 두는 아침 게시판이에요.
큰 시계, 날씨·미세먼지, 시간표, 급식(나이스 자동 연동), 알림장, 지금 해야 할 것, 목소리 신호등,
타이머, 발표자 뽑기, 수업 모드, 칭찬 도장판, 제출 확인, 아침 기분 체크, 지난 기록 보기가 들어 있어요.

---

## 1. GitHub에 올리기 (처음 한 번, 10분)

1. [github.com](https://github.com)에 가입하고 로그인해요.
2. 오른쪽 위 **+** → **New repository**를 눌러요.
   - Repository name: `morning-board` (원하는 이름 아무거나, 영어로)
   - **Public**을 고르고 **Create repository**를 눌러요.
3. 만들어진 화면에서 **uploading an existing file**을 눌러요.
4. 이 폴더의 파일 7개를 끌어다 놓아요.
   - `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `README.md`
5. 아래 **Commit changes**를 눌러요.
6. 위쪽 **Settings** → 왼쪽 **Pages**에 들어가요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
7. 1~2분 기다린 뒤 새로고침하면 위에 주소가 나와요.
   `https://내아이디.github.io/morning-board/`

> **개인정보 걱정은 안 하셔도 돼요.** 저장소에는 게시판 "틀"만 올라가요.
> 학생 이름, 알림장, 기분 기록 같은 내용은 각 컴퓨터의 브라우저 안에만 저장되고,
> GitHub에는 올라가지 않아요. (게시판 안 예시 이름들은 지어낸 이름이에요.)

## 처음 열면

**처음 설정 안내**가 떠요. 다섯 단계만 따라가면 우리 반에 맞춰져요.

1. 우리 반 이름 (이미 쓰던 게시판이 있으면 여기서 "백업 불러오기"로 바로 옮겨 와요)
2. 학생 이름 붙여넣기 (명렬표에서 이름 칸을 복사해도 돼요)
3. 종 시간: 1교시 시작, 수업·쉬는 시간 길이, 중간놀이·점심만 넣으면 시간표가 자동으로 계산돼요
4. 예시 내용 정리 + 기다리는 날(D-day)
5. 급식 학교 연결, 날씨 지역, 시간표, 알람 중 하고 싶은 것으로 바로 가기

나중에 다시 하려면 **선생님 → 쓰는 법 → 처음 설정 다시 하기**.

## 2. 앱처럼 설치하기

1. 교실 컴퓨터 크롬에서 위 주소를 열어요.
2. 주소창 오른쪽 끝의 **설치** 아이콘(모니터 모양)을 누르거나,
   크롬 메뉴(⋮) → **전송, 저장, 공유** → **페이지를 앱으로 설치**를 눌러요.
3. 바탕화면과 시작 메뉴에 "아침 게시판" 아이콘이 생겨요. 창 없이 앱처럼 열려요.

**소리가 처음부터 나게 하려면** (선택)
앱 아이콘 오른쪽 클릭 → 속성 → "대상" 칸 맨 끝에 한 칸 띄우고 아래를 붙여요.
크롬을 모두 닫은 상태에서 이 아이콘으로 열 때만 적용돼요.

```
--autoplay-policy=no-user-gesture-required
```

**컴퓨터를 켜면 저절로 열리게 하려면** (선택)
`Win + R` → `shell:startup` 입력 → 열린 폴더에 앱 아이콘을 복사해요.

## 3. claude.ai 게시판에서 내용 옮기기

1. 지금 쓰던 claude.ai 게시판에서 **선생님 → 설정 → 주간학습 붙여넣기·백업** → **지금 내용 복사**.
2. 새 게시판에서 **선생님 → 설정 → 주간학습 붙여넣기·백업** → 아래 칸에 붙여넣기 → **되살리기** → **저장하고 닫기**.

시간표, 학생 명단, 규칙, 알림장, 급식, 생일, 도장 같은 내용이 모두 옮겨져요.
(오늘 아이들이 고른 기분 기록은 옮겨지지 않아요.)

## 4. 급식 자동 연동

1. 게시판의 **오늘 급식** 박스를 눌러요.
2. 맨 위 **학교 급식 자동으로 가져오기**에 학교 이름을 쓰고 **검색**.
3. 우리 학교를 누르면 바로 급식을 가져와요. 그 뒤로는 매일 저절로 가져와요.

- 인증키가 없으면 **한 주 치씩** 가져오고, 학교 검색 결과도 5개까지만 나와요. 매일 쓰기에는 이것만으로 충분해요.
- 한 달 치를 한 번에 받고 싶으면 [나이스 교육정보 개방 포털](https://open.neis.go.kr)에 가입해서
  인증키를 무료로 받은 뒤, 같은 창의 **나이스 인증키** 칸에 붙여넣어요.
- 박스에 직접 쓴 메뉴가 있으면 그게 먼저 보여요(특식 날 등).
- 나이스 연결이 안 되면 예전처럼 **한 달 치 한 번에 넣기**에 학교 홈페이지 급식표를 붙여넣으면 돼요.

## 5. 날씨·미세먼지

1. 날짜 아래 **날씨·미세먼지 지역 고르기**를 눌러요.
2. 동네 이름(예: 수원, 강남구)을 검색해서 고르거나, **이 컴퓨터 위치로**를 눌러요.
3. 30분마다 새로 가져와요. 인증키가 필요 없어요([Open-Meteo](https://open-meteo.com) 무료 서비스).

- 미세먼지 단계는 환경부 기준(좋음·보통·나쁨·매우 나쁨)으로 보여 줘요.
- 나쁨 이상이면 **바깥 활동은 쉬어요**, 비 올 확률이 60% 넘으면 **우산 챙겨요**가 떠요.
- 미세먼지는 예보 모델 값이라 에어코리아 측정값과 조금 다를 수 있어요.

## 6. 시간표는 주마다 따로 남아요

- **시간표 박스**를 누르면 위에 `◀ 11/23(월) ~ 11/27(금) · 이번 주 ▶`가 있어요. 화살표로 다음 주 시간표를 미리 고칠 수 있어요.
- 고친 내용은 **그 주에만** 들어가요. 지난 주 시간표는 기록으로 그대로 남아요.
- 새 주가 시작되면 **과목과 하교 시각만** 이어받고, 교과서 쪽수·준비물·평가는 비워 둬요.
  ("앞으로 새 주도 이 과목으로 시작하기"를 체크하면 지금 과목이 기본이 돼요.)
- 주간학습안내 붙여넣기(설정 → 주간학습 붙여넣기·백업)에서 **넣을 주**를 고를 수 있어요.
  금·토·일에는 다음 주가 먼저 골라져 있어요.

## 7. 수업 모드 · 지난 기록

- **수업 모드**(`M`): 지금 몇 교시인지, 언제부터 언제까지인지(남은 시간), 지금 해야 할 것만 크게 남아요. 타이머를 켜면 타이머도 보여요.
  띠의 **수업 시간에 저절로**를 체크하면 수업이 시작될 때 켜지고 쉬는 시간에 꺼져요.
- **지난 기록**(`H`, 선생님 메뉴 또는 알림장의 "지난 알림장"):
  - **주간 보기**: 한 주씩 넘기며 그 주 시간표·준비물·평가·알림장·급식을 표 하나로 봐요
  - 알림장: 주별로 묶어서, 낱말 검색도 돼요 (120일)
  - 급식: 지난 메뉴 (90일)
  - 기분: 학생별로 최근 10일 표. 최근 다섯 번 중 세 번 이상 힘든 기분이면 이름이 빨갛게 보여요 (90일 보관, 잠그면 안 보여요)

## 8. 알람 · 학생 기록 · 인쇄

- **알람**(선생님 → 알람): "09:10 우유 마시기"처럼 시각과 할 말을 정해 두면, 그 시각에 화면 가운데 크게 알려 주고 소리가 나요.
  요일을 고를 수 있고, 예시 알람 3개(우유, 급식 줄, 양치)는 꺼져 있으니 켜서 시각만 바꿔 쓰세요.
- **학생 기록**(선생님 → 학생 기록, `R`): 학생을 고르고 칭찬·학습·생활·상담·건강·기타 중 하나를 골라 짧게 남겨요.
  그 학생의 최근 기분도 같이 보여요. **기록 복사**나 **엑셀용 파일 저장**으로 생활기록부 쓸 때 꺼내 쓸 수 있어요.
  잠그면 메뉴와 함께 숨겨져요. GitHub판에서는 이 컴퓨터에만 저장돼요.
- **주간학습안내 인쇄**: 지난 기록 → 주간 보기 → **인쇄하기**. 알림장·급식을 넣을지 고르고,
  "가정에 알려 드려요" 글을 쓰면 A4 한 장으로 뽑혀요. 인쇄 창에서 "PDF로 저장"을 고르면 파일로도 받을 수 있어요.

## 9. 꼭 알아 두실 점

- **저장은 기기마다 따로예요.** 교실 컴퓨터에서 고친 내용은 그 컴퓨터에만 있어요.
  휴대폰으로 열면 따로 저장돼요. 주로 교실 컴퓨터 하나에서 쓰시는 걸 추천해요.
- **브라우저 기록을 지우면 내용이 지워질 수 있어요.** 가끔
  **설정 → 주간학습 붙여넣기·백업 → 백업 파일로 저장**을 눌러 두세요.
  나중에 **백업 파일 불러오기**로 되살릴 수 있어요.
- **아이들이 만질 땐 잠가 두세요.** 선생님 → 잠그기. 풀 때는 "잠김"을 2초 꾹.
  기분 체크 목록은 설정 안에 있어서, 잠가 두면 아이들이 못 봐요.

## 10. 게시판을 고치고 싶을 때

Claude에게 고쳐 달라고 하면 새 `index.html`을 받을 수 있어요.
GitHub 저장소에서 `index.html`을 눌러 → 휴지통 아이콘으로 지우고 →
**Add file → Upload files**로 새 파일을 올려 **Commit** 하면 1~2분 뒤 바뀌어요.
(저장된 내용은 그대로 남아요.)
